# 🧠 ResearchMind AI

## Your Complete AI Research Team

ResearchMind AI is a multi-agent AI research platform that brings together **9 specialized AI agents** into one intelligent research workspace.

Instead of using one AI system for every task, ResearchMind AI divides the research process into specialized agents that can work independently or collaborate through a multi-agent workflow.

> **Research → Analyze → Verify → Cite → Visualize → Summarize → Generate**

---

## ✨ Features

### 🤖 9 Specialized AI Agents

| # | Agent | Purpose |
|---|---|---|
| 01 | 🔎 Research Agent | Web research and information collection |
| 02 | 📄 PDF Analysis Agent | PDF upload, extraction, OCR and analysis |
| 03 | 🧠 Knowledge Agent | Private knowledge-base retrieval |
| 04 | 📝 Report Writer Agent | Professional research report generation |
| 05 | 🔗 Citation Agent | Citations and references |
| 06 | ✅ Fact Checker Agent | Claim verification and fact checking |
| 07 | 📊 Visualization Agent | Actual charts and visual images |
| 08 | 📋 Summary Agent | Research and document summarization |
| 09 | ⚡ Orchestrator Agent | Multi-agent research coordination |

Each agent has a **different responsibility** and can be used independently.

# 🔍 01. Research Agent

The Research Agent performs research on a given topic.

### Capabilities

- Web research
- Information collection
- Source discovery
- Source URLs
- Research summaries
- Comparison of information
- Follow-up questions
- Context-aware conversations
